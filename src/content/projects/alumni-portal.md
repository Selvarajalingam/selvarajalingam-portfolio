## Overview

Alumni Portal is a platform for university alumni and administrators, bringing graduate profiles, opportunities, events and networking into one application.

## Purpose and scope

The project supports alumni registration and community activities, including job opportunities, events, reunions, donations and announcements.

## My role

Independently developed end-to-end.

## Features

- Alumni registration and graduate profiles
- Job opportunities
- Events and reunions
- Networking
- Donations and announcements
- Administrative dashboard

## Technology

The backend stack includes Java 21, Spring Boot, PostgreSQL 16, Flyway, Redis and RabbitMQ. The frontend uses React 19, Vite and Tailwind CSS 4.

Docker is included for development and production. Component connections, deployment topology and test results are not published here yet.
