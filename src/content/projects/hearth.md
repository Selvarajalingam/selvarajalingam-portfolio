## Overview

Hearth is a shared household finance app for two people.

## Purpose and scope

The application brings a monthly overview, financial entries, budgets and savings goals into a shared household finance experience.

## My role

Independently designed and developed end-to-end.

## Features

- Monthly financial overview
- Income, expense, transfer and savings entries
- Filters and budgets
- Savings goals and progress
- Partner invitation and settings
- CSV and PDF exports
- Installable progressive web app

## Technology

The interface uses React 19, TypeScript, Vite, Tailwind CSS 4, Radix UI, Phosphor Icons, Motion and Recharts. Form and data tooling includes React Hook Form, Zod, TanStack Query and Papa Parse.

The project includes PostgreSQL through Supabase, Supabase Auth and PostgreSQL row-level security.

## Testing and delivery tools

The project tooling includes Vitest, Playwright and axe. PDF exports use jsPDF, and PWA tooling includes Vite PWA and Workbox. Vercel and GitHub are included in the delivery workflow. Detailed test results are not published here.
